# Labirinti della community · Community mazes

🇮🇹 [Italiano](#italiano) · 🇬🇧 [English](#english)

## Italiano

Qui ci sono i labirinti di **Lanterna – Il Labirinto Oscuro** creati dai giocatori.

### Come proporre un labirinto

1. Disegna il labirinto con l'**editor di Lanterna**.
2. Quando il controllo dice "Livello valido", premi **Condividi con la community** (nel pannello a sinistra, sezione Community).
3. **Solo la prima volta:** nella finestra che si apre premi **1. Crea la tua copia**. Su GitHub accedi o crea un account (è gratis), premi **Create fork** e torna all'editor.
4. Premi **2. Apri GitHub**: si apre il nuovo file in questa cartella. Se il testo non compare, incollalo tu: l'editor l'ha già copiato (Ctrl+V o Cmd+V).
5. Premi **Commit changes… → Propose changes**, poi **Create pull request**.
6. Un controllo automatico verifica il labirinto. Se è tutto a posto, il proprietario lo guarda e lo approva.

### Regole

- Si possono aggiungere solo file `.txt` in questa cartella (`community/levels/`). Pull request che cambiano altri file non vengono accettate.
- Nome del file: lettere minuscole, numeri e trattini, per esempio `la-torre-di-luca.txt`.
- Il labirinto deve essere valido per il gioco, avere un nome (`name:`) e una strada dalla partenza all'uscita. Massimo 71 × 71 caselle.
- Testi (nome, storia, diario) in tono adatto a tutti: niente insulti, contenuti violenti o volgari, dati personali, link o pubblicità.
- Inviando un labirinto accetti che venga pubblicato in questo progetto e, in futuro, nel gioco, con il tuo nome utente GitHub come autore.
- Il proprietario del progetto può rifiutare o modificare qualsiasi proposta.

## English

This folder holds the mazes for **Lanterna – The Dark Maze** made by players.

### How to submit a maze

1. Draw your maze with the **Lanterna editor**.
2. When the check says the level is valid, press **Condividi con la community** (Share with the community, left panel, Community section).
3. **First time only:** in the window that opens press **1. Crea la tua copia** (make your copy). On GitHub sign in or create a free account, press **Create fork** and go back to the editor.
4. Press **2. Apri GitHub** (open GitHub): the new file opens in this folder. If the text is missing, paste it: the editor has already copied it (Ctrl+V or Cmd+V).
5. Press **Commit changes… → Propose changes**, then **Create pull request**.
6. An automatic check tests the maze. If everything is fine, the owner reviews and approves it.

### Rules

- Only `.txt` files in this folder (`community/levels/`). Pull requests that change other files are not accepted.
- File name: lowercase letters, numbers and dashes, for example `lukes-tower.txt`.
- The maze must be valid for the game, have a name (`name:`) and a way from the start to the exit. At most 71 × 71 cells.
- Texts (name, story, diary) suitable for everyone: no insults, violent or vulgar content, personal data, links or ads.
- By submitting a maze you agree that it is published in this project and, later, in the game, with your GitHub username as the author.
- The project owner may reject or edit any submission.
